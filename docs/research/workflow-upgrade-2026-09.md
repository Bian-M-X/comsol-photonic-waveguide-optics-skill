# 低成本光子逆向设计 workflow 更新报告

历史基线：文献与 COMSOL 性能实测于 2026-09-29，初轮软件验证于 2026-09-30。
本报告持续更新至 2026-10-10，记录 0.6.0 源码更新，契约 schema 仍为 1.0；
发布状态以 GitHub main 与 Actions 为准，源码更新不自动意味着已有 tag 或 PyPI 发布。
以下解析搜索和 CPU/GPU 数值保留为历史基线，
不代表新增原生逆设计的最终验证结果。

## 结论与结构选择

保留一个主 skill，增加按需读取的四条工程路线和一份来源表。暂不拆成多个
独立安装的 skill：端口、模式、相位基准、功率记账、制造声明和证据契约需要共享；
现阶段拆分主要增加同步成本。将来只有出现独立调用场景、独立依赖和独立验证
能力的模块，才值得成为 skill 族成员。

降低成本的优先次序是：减少不必要的全波状态、选择有效的设计变量、用便宜模型
筛选并校准偏差、检查导数和制造映射、保留最终验证预算，最后才是调求解器硬件。
这些策略不能保证任意器件的全局最优或固定加速比。

## 四篇论文如何改变 workflow

| 论文 | 提取出的可操作规则 | 避免的错误 |
|---|---|---|
| He 等，Science Advances 2023，超紧凑量子逻辑门 | 多波长、制造角点、复数矩阵和电路级目标；成功概率单独报告 | 用 50:50 强度分光证明 Hadamard 门；把条件保真度当作确定性成功率 |
| Christiansen 与 Sigmund，JOSA B 2021 教程 | 完整伴随链、滤波与投影导数、逐步二值化、导出几何后复算 | 连续灰度解直接阈值化；把滤波半径或阈值差直接解释为固定 nm 工艺偏差 |
| Molesky 等，Nature Photonics 2018 综述 | 先选择参数/形状/拓扑表示，明确状态方程与目标 | 对高维光滑问题盲目使用群体算法；从一次优化成功推出物理极限 |
| Piggott 等，Scientific Reports 2017 | 线宽、空隙、曲率分别约束；按频率和状态统计伴随成本 | 认为曲率界保证最小线宽；把六波长迭代算成总共两次求解 |

原文页码、DOI、文件哈希标识和补充材料阅读边界见
[文献证据表](../../references/inverse-design-evidence.md)。没有复制论文全文或供应商模型到源库。

2025–2026 年的扩展包括多保真数据、GPU 可微 FDTD、生成式可制造几何和工艺数字孪生。
例如 [PRISM v2](https://arxiv.org/html/2602.15762v2) 提供可微工艺模型与光学敏感度加权修正，
但其虚拟晶圆厂结果不能替代本工艺的 SEM 校准；
[生成式设计规则流形](https://doi.org/10.1002/lpor.71486)适合能摊薄训练成本的重复设计族。
这类方法列为条件接入路线，没有因“更新”而强行安装训练框架或第二套求解器。

## 已实现的能力

1. **预算明确的低维候选建议器。** `photonic optimize suggest` 使用 NumPy 的
   Matérn-5/2 GP、期望改进和约束可行性模型，混合局部与全局候选池。支持
   1–20 个连续变量、一个目标、最多八个标量约束；它只提出候选，不启动求解器。
   每份试验须匹配完整冻结 spec 的 SHA-256。失败计入预算，未完成试验阻止再次
   提议，重复同类失败转入诊断，验证预留不被搜索吞掉。没有把不同保真度混训。
2. **可测试的逆向设计数值组件。** 实现边界归一化锥形滤波的精确转置、tanh 投影
   导数、平滑最坏情况聚合、复数矩阵比较和多步长方向导数检查。滤波不等于最小
   特征 DRC；矩阵相似度同时报告吞吐与幅值误差，避免掩盖损耗。
3. **误差与成本联合分配。** 实现有条件的候选区间比较，以及由任务敏感度决定的
   器件精度分配。若 `sum(L_i e_i) <= E` 且成本为 `sum(a_i/e_i^p)`，最优分配为
   `e_i = E (a_i/L_i)^(1/(p+1)) / sum_j[L_j (a_j/L_j)^(1/(p+1))]`。
   推导与适用条件见[误差预算路线](../../references/multifidelity-and-error-budgets.md)。
   这是标准敏感度传播与成本模型的组合，不声称新定理；点导数和经验拟合不能
   自动提供全区域误差界。
4. **可重用的 COMSOL 性能试验工具。** 新增串行、默认 dry-run 的求解器比较脚本，
   记录输入/输出哈希、失败日志、实际求解和进程时间。每次执行独立 prefs/config/tmp，
   超时只终止自己启动的进程树。既有 Java runner 增加可选 `-Processors`。
5. **完整传播与输入边界修正。** 六份新参考进入 MCP 与包内资源；仍为 13 个工具，
   当前为 35 个资源。修复中文 Windows 下 MCP stdio 的 UTF-8 编码，并拒绝目标值、
   随机种子和预算中的布尔值在 Pydantic 转换后冒充数值。

6. **原生 COMSOL 伴随/MMA 开发示例。** 已实现原创 Java 密度场、Helmholtz
   滤波、镜像、投影和 Maxwell 目标的本地执行链，以及二值几何重建、检查点恢复、
   八源同模型复数 S 矩阵、签名通量和独立验收器。0.6.0 已于 2026-10-10 完成
   选定二值二维替代模型的十九项冻结验证与十三组收敛比较，独立原始矩阵审计
   全部通过；七个离散波长不构成连续带宽、三维或制造结论。结果与谱系见
   [二维合格展示](../showcases/hadamard-2d/README.md)。入口和范围见
   [原生路线](../../references/comsol-adjoint-inverse-design.md)与
   [可执行示例](../../examples/comsol-hadamard-inverse/README.md)。

TuRBO/qMFKG、制造数字孪生和自动 3D 验收仍没有实现或完成接入验证。
公开 `optimize run/resume` 及 MCP solver 仍为计划接口；原生示例走授权的开发执行路线。
新工具没有改变
项目特定的 G1 前置规则，也没有把求解成功自动提升为器件物理验收。

## 可复现实验

### 等预算解析搜索

运行 `python examples/optimization/analytic_coupler.py --output NEW_DIRECTORY`。
模型是未校准系数的对称耦合模公式，不是 COMSOL、工艺模型或真实器件数据。
12 个配对种子，各方法共享五个初始点；总预算 30，其中搜索 24、预留验证六。
训练每次计算五波长 × 三间隙角点；胜出候选在 41 波长 × 五角点上复查一次，
其余五个预留槽位不使用。这里一个槽位是整套候选评估，同时报告其内部状态数。

| 比较项 | GP-EI | 随机搜索 |
|---|---:|---:|
| 每个种子的搜索候选数 | 24 | 24 |
| 验证损失中位数，越小越好 | 0.08849234 | 0.10658265 |
| 配对严格胜出次数 | 9/12 | 3/12 |

中位损失约低 17.0%，但 12 个种子和一个解析函数不足以证明普遍优越。
GP 提议开销中位约 0.013 秒/完整搜索序列；对便宜解析函数，普通解析/局部优化
通常更合适。没有据此宣称全波评估次数减少或 COMSOL 加速。

### 本机 COMSOL CPU/GPU 对照

平台：i9-13980HX，24 核/32 逻辑处理器，64 GB RAM，RTX 5000 Ada Laptop
16,376 MiB 显存，COMSOL 6.4 build 293。使用官方 `waveguide_with_scatterer.mph`
的隔离加载副本：2D 波导与散射体，驱动问题 25,153 DOF；四个 BMA 均重新计算。
仅改变驱动直接求解器，双精度，8 个处理器，每种两次新进程，第二轮反转顺序。
单个原生进程超时上限 180 秒，未触发；官方原模型只读。

| 求解器 | Study 求解时间中位数/s | Batch 进程时间中位数/s | 编译时间中位数/s |
|---|---:|---:|---:|
| PARDISO | 6.119 | 16.855 | 2.931 |
| MUMPS | 6.067 | 16.606 | 2.862 |
| cuDSS | 6.376 | 16.631 | 2.878 |

日志明确记录了 NVIDIA 显卡与实际使用 cuDSS。所比六个实数指标（包括 S21
实虚部）的最大差为 `2.0e-14`。但 `R+T+A+Lsca-1 ≈ 8.87946e-4`，本次没有做
网格/PML/材料收敛，不将求解器之间一致当作物理误差已消除。

这一级小模型没有观察到 GPU 优势；启动、加载与存盘占显著成本。只有两次重复，
不能据约 0.2 秒的差异排列 CPU 求解器优劣，也不能外推到大规模 3D。
未测量 GPU 峰值显存、完整 CPU 核数曲线或大模型 out-of-core 行为。
因此 skill 采用“匹配真实模型实测后选择”，没有默认启用 GPU 或全部逻辑核心。

## 10 月 3 日：PML 与伴随线性化修复

外部有限模端口不能代表辐射连续谱。新版示例将八个导模激励放在内部 slit 上，
波导延伸进入 Cartesian PML；另设无源闭合曲线，同时读取电、磁场以分离入射和
出射模态。PML 采用跨芯层/包层统一的典型波长。旧掩模的受控诊断中，增加原先
PML 的厚度不能修复污染，统一拉伸后入射矩阵接近单位阵；这只支持该模型的修复，
仍需逐候选执行网格、外域、PML 和观测面检查。验收保留原始响应，禁止用入射矩阵
求逆把污染结果修正为通过。实现与限定见[原生路线](../../references/comsol-adjoint-inverse-design.md)。

更隐蔽的问题出现在伴随计算：滤波先收敛后，Maxwell 场可在第二次 Newton 更新
达到小残差，但复用的 Jacobian 的材料耦合项仍可能对应前一轮电场。PML 诊断因此
给出伴随 `+3.94694`、有限差分约 `-2.23832`。仅把终止条件收紧为解修正误差
（`termonres=off`），保留容差与逐次 Jacobian 更新后，目标值变化小于 `6e-12`，
两个扰动方向、每个两个步长的相对误差均小于 `4.3e-6`。日志中的第三次组装与
近零修正支持这一机制；未直接检查组装矩阵。这是该耦合模型的求解器经验，
不是对任意非线性光学问题的通用设置。[COMSOL 官方收敛选项](https://doc.comsol.com/6.4/doc/com.comsol.help.comsol/comsol_api_solver.51.28.html)

独立复现使用不含父任务几何、掩模或检查点的 312 文件源码快照。GPT-6.1-sol
仅凭快照和本地软件，从均匀密度启动；六项方向导数检查先于 MMA。五个训练波长、
最多五次二值阈值试算、十九项锁定验证的最大预算为 32 个原生任务；一个任务包含
多个频率/迭代，不能解释为 32 次 Maxwell 求解。当时完整验收尚未完成；
这一历史配方随后由下述三十六任务配方替代。
