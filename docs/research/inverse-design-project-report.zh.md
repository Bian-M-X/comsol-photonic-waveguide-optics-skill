# 从光学目标到二值器件：光子逆向设计项目图文报告

2026-10-11 | photonic-workflow 0.6.0 | 原生仿真验收完成于 2026-10-10

## 1. 项目完成了什么

本项目把文献方法、本机 COMSOL、伴随优化和独立数值审计连接成一条可长期使用的工作流。设计对象是一个 1.3 × 1.3 µm 的二值材料区域，四条接入波导宽 400 nm。在固定相位约定下，它实现 Hadamard 等效的两输入、两输出复数变换。设计区面积不包含接入波导、端口与吸收边界。

## 2. 为什么强度分光还不够

Hadamard 门需要同时控制输出幅度和相对相位。仅看到两个输出各占一半功率，无法区分正确的相干变换与相位错误的分束器。我们固定逻辑目标 U = [[1,i],[i,1]] / sqrt(2)，以及输入/输出相位矩阵 D = diag(1,-i)，因此 D U D = H，其中 H 是标准 Hadamard 矩阵。这些相位在验收前声明，没有根据结果拟合。

![中心波长的线性场分布](../showcases/hadamard-2d/figures/field-linear.png)

图 2. 1550 nm 中心点的 Hz 场强预览。显示使用插值、物理窗口裁切和峰值归一化，适合解释传播形态；绝对功率、相位精度和收敛判断来自原始数值记录。

每个物理端面在该二维模型中存在 TM0 和 TM1 两个导模，因此一次完整读出需要八个独立输入：TM0 的左、下、上、右，再到 TM1 的左、下、上、右。分析保存原始出射矩阵 A 和入射矩阵 B，逻辑传输矩阵 T 取 A 的第 3、4 行与第 1、2 列（从 1 编号）。除了声明的参考面解析相位修正，不以 A B^-1 校正矩阵，也不拟合独立端口相位。

这一选择使高阶导模泄漏、非理想入射归一化和端口污染有机会被检查出来。完整 8 × 8 导模响应并不意味着辐射连续谱已经完备；辐射终止还需要 PML 和内部闭合通量检查。

## 3. 工作流如何控制计算成本

![从问题定义到审计的工作流](../images/showcase/hadamard-workflow/workflow.png)

图 3. 默认原生 campaign 的最大任务预算。图中任务数是执行单元数，一个优化任务内仍有多次频率、伴随、Newton 和线性求解。

工作流先冻结物理问题、端口基准与验收规则，再验证梯度。通过后用五个波长共同驱动优化，采用粗网格和逐步增强的投影；只有最后阶段使用更细网格。灰度解随后重建为真实二值几何，阈值搜索拥有独立预算。选定掩膜冻结后，预留的 19 个任务只用于验收，不再调参。

| 优化任务 | 投影 beta | 最大外迭代 | 核心网格 | 启动方式 |
|---|---:|---:|---:|---|
| warmup | 2 | 8 | 45 nm | 均匀控制场 |
| coarse | 2 | 32 | 45 nm | warmup 检查点；显式重新配置求解器 |
| projection | 4、8 | 各 40 | 45 nm | coarse 检查点 |
| sharpen | 16 | 40 | 45 nm | projection 检查点 |
| fine | 32 | 40 | 25 nm | sharpen 检查点 |

MMA 步长限制为 0.05，物理滤波半径为 50 nm，包层优化网格为 100 nm。五个训练波长为 1520、1536.61、1550、1565、1580 nm。8 步后重启再做 32 步会重置 MMA 内部历史，因此不能称为与连续运行 40 步完全等价。网格参数是尺寸设置，实际网格与自由度以日志为准。

最大预算为 6 个梯度任务 + 5 个优化任务 + 最多 6 个二值阈值任务 + 19 个冻结验收任务 = 36 个原生任务。新版默认配置已对照实际成功设计谱系核验，阈值规则的软件历史重放也一致；此次没有从零重新执行新版默认的一键式完整原生 campaign。

## 4. 伴随链与二值化的技术细节

控制场 theta_c 首先通过 Helmholtz 滤波：theta_f - rf² laplacian(theta_f) = theta_c，边界采用零通量。随后用坐标映射 (min(x,y), max(x,y)) 实现 y=x 镜像，再经 tanh 投影得到材料密度 rho。介电常数采用 eps_clad + (eps_core - eps_clad) rho。投影 beta 从 2 逐步增至 32，让优化从平滑设计过渡到接近二值的设计。

对一个逻辑输入，记目标输出振幅为 a、b。原生 coherent 目标使用 Q = (|a-i b|² - (w-1)|a+i b|²)/2，其中 w=10；等价于目标端口总功率减去 w 倍正交目标分量功率。COMSOL 最大化五个训练波长中的最小 Q，从而同时约束吞吐与相位偏差。最终验收仍直接计算两输入矩阵指标，不以优化目标值代替验收。

伴随法沿“控制场 → 滤波 → 镜像 → 投影 → Maxwell 方程 → 目标”反传梯度。每个指定方向用中心差分 [J(theta+h d)-J(theta-h d)]/(2h) 对照伴随方向导数；步长为 0.001 与 0.0005。六个最终默认检查的最大相对误差为 2.6857e-5；每次比较要求绝对误差小于 1e-6 或相对误差小于 0.002。这支持指定初始密度、方向和配置，不证明所有方向都正确。

项目中的关键修复来自失败实验：PML 条件下，过松的耦合求解终止准则可能让灵敏度使用前一材料场的 Jacobian。最终链采用全 Newton 步、每次更新 Jacobian 和解误差终止准则，并再次检查方向导数。二值导出曾暴露插值导致的镜像偏差；现在先对采样场做最小二乘对称化 [f(x,y)+f(y,x)]/2，再提取等值轮廓。

二值几何来自滤波场 theta_f 的 5 nm 采样轮廓，而不是简单删除灰度像素。每个阈值都会改变真实几何并触发新求解。六次已观察阈值依次为 0.5、0.495、0.505、0.475、0.4618030405255367、0.4683617431984674；最终值来自符号括区间内的割线插值。新版策略限制阈值区间 [0.44,0.53]，相对最佳已观察有限失衡值的最大步长为 0.02，最多六次候选。阈值范围是搜索参数，不改变物理验收门限。

滤波半径、5 nm 采样间距与 beta 都不能直接解释为制造最小线宽或工艺偏差。流程不静默删除小岛、孔洞或细桥；制造约束需要显式 DRC 与工艺模型。

## 5. 冻结后的性能与数值检查

![七个实际离散波长的性能](../showcases/hadamard-2d/figures/spectrum-discrete.png)

图 4. 七个实际计算点，没有连线、插值或统计误差棒。五个训练点之外，1543.3 和 1572.3 nm 是掩膜冻结后才检查的保留波长。图中所有点采用 20/80 nm 核心/包层网格；1550 nm 图点因此不同于下表 25/100 nm 的名义中心点。

| 指标 | 名义中心点 | 19 次验收最差值 | 冻结门限 |
|---|---:|---:|---:|
| eta_all = sigma_min(T)² | 0.9475064821 | 0.9246576286 | ≥ 0.9 |
| 六态最小条件保真度 F6 | 0.9999822474 | 0.9995299555 | ≥ 0.987 |
| 条件 Choi 重叠 | 0.9999822822 | 0.9995300228 | ≥ 0.987 |
| 两个基输入的输出功率比 | 1.01141 / 0.988718 | 0.9215083 至 1.0851774 | 0.9 至 1.1 |

eta_all 对任意归一化复逻辑输入求最差目标输出功率；F6 只在 0、1、+、-、+i、-i 六个输入态上取最小条件保真度。条件 Choi 重叠为 |Tr(U†T)|² / [2 Tr(T†T)]。吞吐与条件保真度分开报告，避免归一化隐藏损耗。

19 次冻结运行覆盖中心和非中心波长网格细化、外域与端口窗口、PML 厚度/强度、模态投影面及两个保留波长。13 组配对比较要求吞吐绝对变化不超过 0.005、F6/Choi 不超过 0.002、两个功率比不超过 0.02。另检查 sigma_max(A) ≤ 1.005、互易残差 ≤ 0.005、||B-I||₂ ≤ 0.005、镜像残差 ≤ 0.005，以及八个输入各自的带符号内部通量闭合残差 ≤ 0.005（相对声明的 1 W/m 入射功率）。

## 6. 成本、硬件与证据层级

| 单独记录的工作 | 工作量 | 编译时间 / s | Batch 时间 / s |
|---|---|---:|---:|
| 选定的成功优化谱系 | 5 任务；206 次频带评估；1030 个名义训练频率状态；另 40 个中心驱动状态 | 17.3772 | 4152.8320 |
| 已发生的先前阈值搜索 | 5 任务；40 个驱动状态 | 16.2941 | 192.1051 |
| 最终名义中心点 | 1 任务；8 个驱动状态 | 3.4502 | 36.7775 |
| 独立冻结验收 | 19 任务；152 个驱动状态 | 91.5722 | 948.9223 |
| 最终默认梯度链检查 | 6 任务；12 次差分比较 | 29.1362 | 382.9108 |

这些是分别记录的工作类别，不是全部研发成本。更早失败分支、梯度试验、掩膜筛选和读出恢复仍有成本；训练频率状态数不包括伴随、Newton 或线性求解。Batch 包含导出与存盘，不能解释为纯求解内核时间。

本机硬件为 i9-13980HX、64 GB 内存、RTX 5000 Ada Laptop，COMSOL 6.4 build 293。最终原生任务采用一个 worker、8 个 CPU 线程。此前在 25,153 自由度小基准上，PARDISO、MUMPS 与 cuDSS 的 Batch 中位时间约为 16.855、16.606、16.631 秒，未观察到 GPU 优势；两次重复的小模型结果不能外推到大型三维器件。

项目区分四种证据：软件测试验证接口和计算逻辑；公开 verifier 复算导出的原始矩阵与数值自洽性；本地原生收据绑定输入、源码与求解产物；器件验收检查声明的物理模型与数值条件。公开包保留 20 条数值记录（中心点 + 19 次验收）、13 组比较和原始来源哈希，但省略重型 MPH、完整控制台和原始场数组，所以明确返回 native_receipts_reverified=false、native_execution_reproduced=false。

## 7. 如何继续复现与使用

从仓库根目录执行以下命令可进行公开数值复核，不启动 COMSOL：

```console
python -m pip install -e ".[inverse-design]"
python docs/showcases/hadamard-2d/verify.py
python docs/showcases/hadamard-2d/plot_spectrum.py
```

要重算冻结器件，按[展示说明](../showcases/hadamard-2d/README.md)从 bundle 导出精确配置，使用 mask.json 在全新目录运行 run.py，再执行 analyze.py 和 13 组冻结比较。要从均匀密度重新设计，则按[原生示例](../../examples/comsol-hadamard-inverse/README.md)先查看 campaign 计划，再用 --execute 启动授权求解。两种复现回答不同问题，应分别记录成本与结果。

本地项目已按源码、实验、验证、发布、论文和交接记录归档；日常使用整理后的正式源码入口，旧驱动通过有作用域的临时 Windows junction 保持兼容，退出时清理链接。可再生中间产物按台账精简，终态模型、原始数值、日志及已识别的续跑输入保留。目录与 SHA-256 清单应按当前核心清单核验；历史收据不表示所有可再生产物仍在线，也不能替代 COMSOL 许可证、软件版本一致性或新的物理验证。

下一步若追求真实器件性能，应先建立经校准的堆栈与模态模型，再补三维垂直辐射、工艺约束和制造误差检查。现有流程可复用预算、检查点、复数目标和冻结验收机制；不能直接把二维数值推广成制造结论。
